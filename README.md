## Deskripsi
Campus Lost & Found merupakan aplikasi mobile
berbasis Flutter yang membantu mahasiswa
melaporkan dan menemukan barang hilang
di lingkungan kampus.

## Tujuan
- Memudahkan pelaporan barang hilang.
- Memudahkan pelaporan barang ditemukan.
- Membantu pencarian informasi barang.
- Mempermudah komunikasi dengan pelapor.

## Fitur Utama
1. Lapor Barang Hilang
2. Lapor Barang Ditemukan
3. Daftar dan Pencarian Barang
4. Detail dan Kontak Pelapor
5. Pembaruan Status Laporan

## Teknologi
- Flutter
- Dart
- Firebase Cloud Firestore
- GitHub


## Cara Menjalankan
1. Clone repository.
2. Buka folder project.
3. Jalankan flutter pub get.
4. Jalankan flutter run.
